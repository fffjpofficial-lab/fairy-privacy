1. 本サービスについて

  • 本アプリは、事務所が運営する Fairy に所属するタレント（以下「利用者」）のための、勤務と実績の管理のアプリです。Fairy の専用のサービスで、一般向けのサービスではありません。
  • 本サービスは、事務所から管理の業務を受託している個人事業主 浜田 麻矛（以下「運営者」）が開発・提供し、事務所がその管理の業務のために利用します。
  • 事務所は、本サービスの運用と、そのために必要な利用者の情報の取り扱いを運営者に委託しています。運営者は、Fairy の管理・運営の業務のためだけに利用者の情報を取り扱い、他の事業には利用しません。
  • 本アプリのアカウントの発行と、利用者の情報の登録・管理は事務所が行います。本アプリの中でアカウントを作ることはできません。

2. 取り扱う情報

事務所は、本サービスで次の情報を取り扱います（実際の取り扱いは、委託を受けた運営者が行います）。

2.1 利用者が本サービスで入力・送信する情報

  • ログインID（8桁の数字）とパスワード
    • ログインIDは、認証の仕組みの中で、ログインIDから作った連絡に使えない形式上のアドレスとして保存します。本物のメールアドレス・電話番号は入力しません。
    • パスワードは認証の仕組みの中で不可逆な形（ハッシュ）で保存し、運営者・事務所を含めて誰も元のパスワードを見ることはできません。
  • 出勤予定の登録・変更・取り消しの内容（日時・勤務の方法）、補填日の登録の内容
  • パスワードの変更の操作
  • 初回のパスワード設定・パスワードの再設定のときに入力する設定コード・再設定コード
    • これらは事務所のスタッフから受け取るものです。照合のための値だけを保存します。

2.2 本サービスの利用に伴って記録される情報

  • ログインの記録（ログインの日時、接続元の IP アドレス、端末・アプリの種類を示す情報（User-Agent））
  • 出勤予定の変更などの操作の履歴（いつ・誰が・何を変更したか）
  • 初回のパスワード設定・再設定のページでは、試行の回数を制限するため、接続元の IP アドレスを鍵付きのハッシュで変換した値を保存します。IP アドレスそのものは、この目的では保存しません。
  • 本アプリ・Webページとの通信の記録（アクセスの日時、接続元の IP アドレス、User-Agent）は、§6 の事業者のサービスの記録として、各事業者の定める期間保存されます。

2.3 事務所が登録・管理し、本アプリで表示する情報

  • 表示名、所属店舗、ログインID
  • 出勤予定、割り当てられたルーム、欠勤と補填の状況
  • 月間の目標、実績のポイント（配信サイトごとの集計と内訳）、稼働している配信サイトの名称
  • 月次の休止の状況

事務所は、このほかに氏名・生年月日・配信サイトでのIDやニックネームなどの管理用の情報を本サービスで管理していますが、これらは事務所の管理者だけが扱い、本アプリには表示されません。

2.4 配信サイトから事務所が受け取る実績のファイル

  • 事務所は、配信サイトから日ごとの実績のファイル（CSV）を受け取り、本サービスに取り込みます。ファイルには、配信サイトでの利用者のID とポイントのほか、配信サイトによってはニックネーム（配信の上の名前）や氏名が含まれます。
  • 本サービスのデータベースに取り込むのは、配信サイトでのID とポイントなどの数値だけです。ファイルの中のニックネーム・氏名は取り込みません。
  • 実績の根拠として、受け取ったファイルは内容を変えずに非公開の保存領域に保存し、暗号化した複製を別の事業者に保管します（§6・§7）。これらのファイルは本アプリには表示されません。

2.5 取得しない情報

本アプリは、位置情報、連絡先、写真、カメラ、マイク、広告の識別子を取得しません。広告・利用状況の分析・行動の追跡（トラッキング）のためのツールを使っていません。

3. 利用の目的

事務所は、取り扱う情報を次の目的にだけ利用し、Fairy の管理・運営の業務以外には利用しません。

  1. 利用者の本人確認とログインの管理
  2. 出勤予定・ルーム・欠勤と補填の管理と表示
  3. 目標と実績（ポイント）の表示
  4. 不正なアクセスの防止とセキュリティの確保
  5. 操作の履歴の記録と、問い合わせ・トラブルへの対応
  6. 事務所の勤務・実績の管理の業務

広告の配信やマーケティングには利用しません。

4. 端末に保存する情報

  • 本アプリは、ログインの状態を保つために、ログインの情報（認証用のトークン）を端末のアプリ専用の保存領域に保存します。
  • この情報は、端末のバックアップや機種変更のときの移行の対象にしません。
  • ログアウトするか、本アプリを削除すると消えます。

5. 第三者への提供

事務所は、次の場合を除き、利用者の情報を第三者に提供しません。

  • 利用者の同意がある場合
  • 法令に基づく場合
  • 人の生命・身体・財産の保護のために必要で、本人の同意を得ることが難しい場合
  • その他、個人情報保護法で認められる場合

6. 委託と外部のサービスの利用

事務所は、本サービスの運用を運営者に委託しています（§1）。運営者は、本サービスを運用するために次の事業者のサービスを利用し、情報の保存・処理を任せています。

事業者用途保存・処理の場所
Supabase Pte. Ltd.（シンガポール。サポート・運用は米国の Supabase, Inc.） データベース、認証、サーバーの処理、実績のファイル（§2.4）の保存 データベース・認証・ファイル・バックアップは日本（東京）。サーバーの処理（Edge Functions）は地域を固定しておらず、通常は利用者に近い地域で行われます。運用の記録（ログ）は日本の国外（欧州連合の域内。国名は公表されていません）で保存され、障害の調査やサポートの対応は日本の国外から行われることがあります
Vercel Inc.（米国） Webページ（初回のパスワード設定・再設定のページ）と、事務所の管理者が利用者の情報を扱う管理用の Web アプリの配信・処理 処理の地域を日本（東京）に設定しています。ページの静的な部分は、利用者に近い配信の拠点から配信されます。運用の記録は米国その他の国で扱われることがあります（保存する国は公表されていません）
Backblaze, Inc.（米国） 実績のファイル（§2.4）の、暗号化した複製の保管 米国（東部）。複製は、Backblaze に送る前に本サービスの中で暗号化しています。復号の鍵は運営者が管理し、Backblaze には渡していません

上の事業者は、シンガポールと米国の事業者です。データベースは日本（東京）に保存しますが、運用の記録（ログ）の保存や、障害の調査・サポートの対応などで、一部の情報が日本の国外で扱われることがあります。

運営者は、Supabase と Vercel を、各社の利用規約に組み込まれたデータ処理の条項（運営者の指示に従った取り扱い、安全管理、再委託の管理、漏えいなどがあった場合の通知などを定めたもの）の下で利用しています。Backblaze には、暗号化した複製だけを預けています。日本の国外にある事業者による取り扱いについて、各事業者が講じている措置と、関係する国の個人情報の保護に関する制度についての情報は、§12 の連絡先にご請求いただければ提供します。

7. 保存の期間

  • 業務の記録（出勤予定とその変更の履歴、実績、操作の履歴）は、勤務・実績の履歴を正確に残し、事務所の業務（勤務と実績の確認、問い合わせ・トラブルへの対応、法令に基づく対応）に用いるため、退店・休止・アカウントの停止の後も削除せずに保存します。
  • 退店などの後は、アカウントを停止し、本アプリを利用できない状態にします。
  • 配信サイトの実績のファイル（§2.4）は、実績の根拠として削除せずに保存します。暗号化した複製は、少なくとも365日は削除を防ぐ設定で保管します。
  • ログインの状態の記録（セッション）は、ログアウトやパスワードの再設定のときに削除されます。ログインの記録（ログインの日時・接続元の IP アドレスなど）は、不正なアクセスの防止とセキュリティの確保のために保存します。
  • 試行の回数の制限のための変換した値（§2.2）は、制限の期間が過ぎた後、順次削除します。
  • 利用者からの利用の停止・削除などのご請求には、§9 に従って対応します。業務の記録で保存が必要なものは、削除ではなく利用の停止で対応する場合があります。法令により削除が必要な場合は、法令に従って削除・匿名化します。

8. 安全管理

  • 通信はすべて暗号化（HTTPS）しています。
  • 利用者は自分の情報だけを見られます。他の利用者の情報は、データベースの段階で読めないように制限しています。
  • パスワードは不可逆な形で保存し、誰も閲覧できません。
  • 事務所の管理者の閲覧・操作の範囲を役割と店舗ごとに制限し、重要な操作の履歴を記録しています。
  • 初回のパスワード設定・再設定のコードには有効期限と試行回数の制限があります。
  • 配信サイトの実績のファイルは非公開の保存領域に置き、外部の事業者に預けるのは暗号化した複製だけです。
  • 外国の事業者の利用: 本サービスでは、シンガポールと米国の事業者のサービスを利用しています（§6）。データベースは日本に、実績のファイルの暗号化した複製は米国に保存し、運用の記録は欧州連合の域内などの国外で扱われることがあります。
  • 外国における個人情報の保護に関する制度：上の事業者の所在国（シンガポール・米国）と、情報が保存・処理される国・地域（日本のほか、米国・欧州連合）について、個人情報保護委員会が公表している情報などにより個人情報の保護に関する制度を把握したうえで、上記の措置を講じています。
    • 米国: 連邦の包括的な個人情報の保護の法律はなく、分野ごと・州ごとの法律があります。
    • シンガポール: 個人データ保護法があります。捜査機関が事業者に情報の提出を命じることができる制度があります。
    • 欧州連合: 個人情報保護委員会が、日本と同等の水準の個人情報の保護の制度があると認めた地域です。

9. 開示・訂正・利用停止などの請求

  • 利用者は、事務所が保有する自分の情報について、利用目的の通知、開示（第三者への提供の記録の開示を含む）、内容の訂正・追加・削除、利用の停止・消去、第三者への提供の停止を請求できます。
  • 請求は、所属店舗のスタッフ、または §12 の連絡先へご連絡ください。請求の方法とご本人であることの確認の方法は、受付のときにご案内します。
  • 事務所は、ご本人であることを確認したうえで、法令に従って遅滞なく対応します。ご請求に応じられない場合は、その理由をお知らせします。手数料はいただきません。
  • 本アプリにはアカウントを削除する機能はありません。アカウントの停止・削除のご希望も、同じ窓口で受け付けます。業務の記録で保存が必要なものは、削除ではなく利用の停止で対応する場合があります（§7）。

10. 未成年の方について

本アプリは、Fairy に所属する18歳以上の方を対象としています。18歳未満の方は利用できません。

11. このポリシーの変更

事務所は、法令の改正や本サービスの内容の変更などに応じて、このポリシーを変更することがあります。変更するときは、変更の内容と効力が生じる日をこのページに掲載します。利用者に影響のある重要な変更は、効力が生じる前に所属店舗を通じてお知らせします。
